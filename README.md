# CroppTech Commerce Store

A standalone fashion commerce storefront for CroppTech, separate from the main CroppTech website.

**Brand line:** BUSINESS MOVES WITH COMMERCE.

## Store direction
- Men's and women's fashion, with linen as the lead collection
- Deep crimson accent, warm linen neutrals, white and charcoal
- Real fashion photography and properly licensed/supplier-approved product imagery
- Responsive storefront foundation

## Current build
This first release establishes the Next.js storefront shell and homepage experience. Product imagery currently acts as editorial/demo imagery only; it does not represent confirmed CroppTech inventory, pricing, stock, or supplier relationships.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.
